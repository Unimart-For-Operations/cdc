# feat(freezer): port all idpctl commands to unimart freezer

This commit completes Phase 2 of the idpctl-to-unimart migration. All
17 idpctl commands have been reimplemented as native Go code inside
unimart's freezer aisle, organized across 10 cmd files and 8 internal
packages with 9 test files. The freezer stubs are gone — replaced by
working implementations that shell out to the same CLIs idpctl used
(kind, kubectl, colima, docker, podman, go, make). Documentation
(AGENTS.md, README.md, CHANGELOG.md) updated to reflect the new
reality. Phase 3 (deprecate the idpctl binary) is next.
