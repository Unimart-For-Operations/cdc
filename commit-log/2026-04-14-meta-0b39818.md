# feat(open): add unimart open command for full IDP platform startup

This commit adds the signature command for the unimart CLI. Where
`freezer up` gives fine-grained control over platform lifecycle,
`unimart open` is the opinionated one-shot that brings everything
online — prerequisites, build, platform creation, repo publishing,
and browser launch — with sensible defaults and minimal flags. The
shared helpers extracted during this refactor ensure both commands
stay in sync. The `packages/` directory is ready for future custom
ArgoCD Application YAMLs as repos gain Kubernetes content.
