# feat(sandbox): achieve 1:1 parity with cmdr tty + tui modules

The sandbox container now imports cmdr's Nix modules directly via
home-manager, achieving 1:1 parity with the workstation's tty and tui
feature sets. All 18 tools are present with full configuration: zsh
(25 aliases, autosuggestions, syntax-highlighting, compinit), tmux
(resurrect + continuum, layout scripts), nvim (AstroNvim v5 + 11 LSP
servers + 5 formatters), lazygit, k9s, yazi (plugins), bat (TwoDark),
atuin, direnv, and more. Changes to cmdr modules automatically
propagate to the sandbox on next build — treating the container as a
unit test for the workstation config.
