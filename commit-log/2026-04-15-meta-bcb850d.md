# refactor(gitmodules): use relative URLs for portable submodule links

Submodule links in the Gitea web UI were navigating to GitHub because
.gitmodules contained absolute GitHub SSH URLs. Relative URLs fix
this by resolving against the current host, making the meta repo
portable across any Git server that hosts the full org.
