# fix(backstage): prefill repoUrl in nix-sandbox template

The Nix Sandbox scaffolder form previously used a free-text Repository
picker, which invited pasting a full clone URL and caused the gitea:commit
action to build a malformed repo and fail with a 404. Replace it with a
prefilled gitea: repo URL string so the correct shared repo is selected.
