# refactor(stockroom): dynamic submodule discovery from .gitmodules

The stockroom and newsstand commands previously hardcoded submodule
lists, requiring Go code changes whenever a submodule was added or
removed. This refactor reads .gitmodules at runtime, making the CLI
self-configuring. The stockroom update command also gains automatic
docs sync — when a source repo's docs/ directory changes, the cdc
vault is synced and auto-committed, completing the self-reconciling
documentation pipeline from the command line (complementing the
post-commit hook path).
