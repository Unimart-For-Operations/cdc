# fix(packages): add CRD sync-wave and server-side apply for ordering

ArgoCD failed to sync because it tried to apply Prometheus CRs before
the CRDs were registered. Sync waves ensure CRDs apply first; skip-
dry-run prevents pre-apply validation failures for not-yet-known types;
server-side apply avoids the 262 KB annotation ceiling entirely.
