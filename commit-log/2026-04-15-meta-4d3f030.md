# feat(ci): add Gitea Actions runner and CI workflow

This brings CI to the in-cluster Gitea instance. Every push to any
repo with workflow files triggers jobs on the local Kind cluster —
no cloud CI needed. The runner deploys as part of the platform via
ArgoCD custom packages, making it fully declarative and automatic.
The CI workflow validates Go code (fmt, vet, build, test) on every
push, providing server-side enforcement alongside the existing local
git hook gates.
