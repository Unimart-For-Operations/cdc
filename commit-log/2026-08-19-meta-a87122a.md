# feat(packages): add kube-prometheus-stack monitoring stack

Deploys the Prometheus/Grafana/Alertmanager monitoring stack through the
idpbuilder custom-package pipeline (cnoe:// package + ArgoCD Application),
the same mechanism as backstage and nix-sandboxes. Embeds the CRD
upgrade hook so the violation that left nginx without permissions cannot
recur: CRDs install as a PreSync hook before the operator comes up.
