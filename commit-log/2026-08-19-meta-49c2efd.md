# fix(packages): use helm.includeCrds instead of upgradeJob for CRDs

The kube-prometheus-stack CRD upgrade hook bundles all CRDs into a
single bz2-compressed ConfigMap. ArgoCD's client-side apply stamps
the full manifest into kubectl.kubernetes.io/last-applied-configuration,
blowing past the 262144-byte annotation ceiling. Switching to
helm.includeCrds renders each CRD as a standalone manifest, side-
stepping the size limit entirely.
