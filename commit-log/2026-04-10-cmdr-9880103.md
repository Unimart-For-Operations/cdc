# fix(hooks): correct commit-log date format and cdc auto-commit

Fixes three bugs discovered during the first real-world use of the hook
gate system. Commit-log entries now get correct date-based filenames,
the cdc vault is properly detected as a git repo in submodule contexts,
and auto-commit operations no longer fail from inherited git environment
variables. The self-reconciling docs pipeline is now fully functional.
