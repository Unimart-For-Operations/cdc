# feat(nix-sandbox): bake nvim-astro, opencode, and cmdr tmux keybinds into sandbox-tty

Sandboxes now match the workstation's editor and terminal ergonomics:
nvim launches the user's AstroNvim distro (auto-copied from the cmdr
submodule at image build time), opencode ships in the toolset with a bare
config, and tmux uses the cmdr keybinding profile (prefix C-Space, vim pane
nav, |/ - splits, vi copy-mode).
