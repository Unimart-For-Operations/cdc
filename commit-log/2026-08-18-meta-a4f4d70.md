# fix(nix-sandbox): include :8443 port in terminal links

The Sandbox-terminal hosts are only reachable on the host via the mapped
ingress port 8443, but the template's output link and the scaffolded
catalog-info.yaml link omitted it, so generated URLs hit 127.0.0.1:443 where
nothing listens.
