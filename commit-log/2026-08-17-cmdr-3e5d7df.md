# fix(vscode): shim ripgrep path for darwin build

VS Code >= 1.129 ships the macOS ripgrep binary under node_modules.asar.unpacked, but the pinned nixpkgs still chmods the legacy node_modules path, failing the aarch64-darwin build. The prePatch shim lets vscode build again.
