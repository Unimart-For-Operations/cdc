# feat(nix-sandbox): run sandboxes on sandbox-tty with TTY toolset

Scaffolded nix sandboxes previously ran bare nixos/nix. They now default to a
new sandbox-tty image carrying the bare-minimum TTY toolset (zsh, tmux, nvim,
yazi, starship, fzf, zoxide, bat, eza, git, ripgrep, fd, openssh) via a
pinned nixpkgs profile, built and loaded by unimart alongside the terminal
image. The in-browser terminal now opens zsh instead of /bin/sh.
