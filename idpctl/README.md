# Documentation

CLI tool for managing the [idpbuilder](https://github.com/idpbuilder/idpbuilder) development workspace. Handles the full lifecycle: prerequisite installation, Docker/Colima management, building from source, cluster creation, status monitoring, and teardown.

Part of the [idpbuilder](https://github.com/idpbuilder) GitHub organization.
